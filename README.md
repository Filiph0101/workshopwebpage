# Hörby Bilverkstad

En statisk React/Vite-hemsida för Hörby Bilverkstad. Besökare kan läsa om
tjänsterna och trycka på telefonnumret eller knapparna för att ringa direkt från
mobilen.

## Kör lokalt

```bash
cd frontend
npm install
npm run dev
```

Frontend startar på `http://localhost:5173`.

## Bygg för hosting

```bash
cd frontend
npm run build
```

Den färdiga statiska sidan hamnar i `frontend/dist/`.
